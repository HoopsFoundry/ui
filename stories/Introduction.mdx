# HoopsFoundry UI

Komponenten-Bibliothek für Basketball-Apps, zum Beispiel Spielbericht, Scoreboard, Vereinsregister und Live-Scoring. Sie ist kein offizielles Designsystem eines Verbands; BBV und DBB sind mitgelieferte Themes. Dieses Storybook ist die Referenz: Jede Komponente hat eine Seite mit Beispielen, Zuständen, Props, Code und Dos und Don'ts.

<Canvas of={IntroductionStories.Welcome} />

## Was ist drin

- **Tokens:** `tokens.css` (CSS-Variablen), `tokens.json` (Design Tokens Community Group) und `tailwind.preset.js`.
- **CSS:** `components.css` mit den Vanilla-Klassen (`hoops-btn`, `hoops-card`, `hoops-tabs`, …), die einzige CSS-Quelle für Svelte, React und Seiten ohne Build-Schritt.
- **Svelte:** Komponenten unter `svelte/`, einzeln importierbar (`@hoopsfoundry/ui/svelte/Button`).
- **React:** dieselben Komponenten aus `@hoopsfoundry/ui/react`.
- **Storybook:** diese Seiten, mit Hell/Dunkel, A11y-Prüfung und den Code-Beispielen in drei Fassungen.

## Marken, Schrift, Hell und Dunkel

- **Marke:** BBV (Ink · Amber · Sky, Standard) und DBB (Schwarz · Gold · Orange), umschaltbar mit `data-brand="dbb"` auf `<html>`. Komponenten lesen nur Rollen-Tokens und `--hoops-*`, die Marke tauscht deren Werte aus. Mehr auf der Seite [Colors](?path=/docs/foundation-colors--docs).
- **Schrift:** unabhängig von der Marke mit `data-type="dbb"` (Rubik und Sucrose mit Fallback Barlow Condensed statt Manrope und Sora). Mehr auf der Seite [Typography](?path=/docs/foundation-typography--docs).
- **Hell und Dunkel:** automatisch nach OS-Präferenz, erzwungen mit `data-theme="light"` oder `data-theme="dark"` auf `<html>`.
- **Barrierefreiheit:** WCAG 2.1 AAA für alle Text-Paare, Fokus-Ring gestrichelt in Gold/Amber ([Focus & Hover](?path=/docs/foundation-focus-hover--docs)), Touch-Ziele in den Stufen 44, 56 und 64 px.

## Die Werkzeugleiste

Oben im Storybook stehen die Schalter, die auf allen Seiten wirken:

- **Marke:** BBV oder DBB.
- **Schrift:** Standard (Sora, Manrope) oder DBB-Original (Rubik, Sucrose).
- **Theme:** Hell oder Dunkel.
- **Fassung:** welche Code-Beispiele die Seiten zeigen: Vanilla (HTML und CSS), Svelte oder React.
- **Sprache:** Deutsch oder Englisch für die eingebauten Texte der Bausteine (Beschriftungen, `aria-label`, Statuszeilen); die Doku-Texte bleiben deutsch ([Internationalisierung](?path=/docs/foundation-internationalisierung--docs)).
- **Zustand:** erzwingt Hover, Fokus oder Aktiv auf den Vorschauen einer Seite, damit du sie ohne Maus und Tastatur prüfen kannst.

Marke, Schrift, Theme, Sprache und Zustand wirken auf Vorschauen, die direkt auf der Seite stehen; Vorschauen im eigenen Rahmen (iframe) behalten ihre Einstellung.

## Einbinden

```html
<link rel="stylesheet" href="fonts/fonts.css" />   <!-- selbst gehostete Schriften, optional -->
<link rel="stylesheet" href="tokens/tokens.css" />
<link rel="stylesheet" href="css/components.css" />
```

Für React installierst du das Paket mit seinen Peer-Abhängigkeiten und importierst Stile und Komponenten:

```bash
npm install github:HoopsFoundry/ui#v0.10.0 react react-dom @radix-ui/react-dialog
```

```tsx
import '@hoopsfoundry/ui/tokens.css';
import '@hoopsfoundry/ui/components.css';
import { Button } from '@hoopsfoundry/ui/react';
```

Svelte-Komponenten importierst du einzeln über den Path-Export, etwa aus `@hoopsfoundry/ui/svelte/Button`. Tailwind-Nutzer laden `components.css` nach `@tailwind base`. Die ausführliche Anleitung steht in der `README.md`.
