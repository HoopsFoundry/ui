[[glossary]]
== Glossar

[cols="1,3",options="header"]
|===
|Begriff |Bedeutung in dieser Dokumentation
|DSS |Digital Sports System; Designsystem für Basketball-Anwendungen
|Token |Benannter Gestaltungswert beziehungsweise Verweis auf einen Wert
|Rollen-Token |Semantischer Wert wie Aktion, Oberfläche oder Text statt konkreter Farbpalette
|Adapter |Plattformspezifische Umsetzung gemeinsamer Verträge
|Parität |Dokumentierte Gleichwertigkeit von Ausgabe und Verhalten; nicht zwingend identischer Quellcode
|SSR |Serverseitige Ausgabe ohne vorausgesetzte Browserumgebung
|Lifecycle |Initialisierung, Aktualisierung und Aufräumen einer Instanz
|Renderfunktion |Erzeugt Ausgabe aus Eingaben; zusätzliche Vanilla-APIs sind geplant
|Mount |Bindet Ausgabe und gegebenenfalls Verhalten an ein DOM-Element
|ADR |Architecture Decision Record mit Kontext, Entscheidung, Status und Konsequenzen
|MCP |Model Context Protocol; Zugriffsschicht für Agent-Werkzeuge und Kontext
|Baseline |Erste prüfbare Architekturfassung, kein vollständiger Implementierungsnachweis
|===
